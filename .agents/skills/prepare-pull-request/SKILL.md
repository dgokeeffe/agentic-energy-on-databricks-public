# Prepare the pull request

Confirm focused and complete tests, eval, independent `PASS`, safety checks,
`git diff --check`, no secrets, and no staged unrelated files. Summarise the
operator outcome, exact changes, test results, prepared or live status, and
remaining uncertainty. Use `Closes #N` for the selected GitHub issue. Do not
claim deployment or platform evidence that was not run. A person then accepts,
sends back, rejects, or stops; only a person may authorise merge, deployment,
provisioning, grants, live data, schedules, or production promotion.
