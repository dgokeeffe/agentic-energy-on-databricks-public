# Agentic Energy workshop agenda

The [facilitator run of show](../docs/facilitator/workshop-run-of-show.md) is the
only clock source.

| Time | Pair activity |
|---|---|
| 09:45 | preflight and form cross-functional pairs |
| 09:58 | select one `workshop-ready` GitHub issue |
| 10:18 | inspect the issue and `nemweb_foundation/`; define measurable requirements |
| 10:48 | propose exact files, tests, eval, review, and stops; obtain human approval |
| 11:08 | branch, implement, and run focused deterministic tests |
| 12:00 | save the branch and pair record; break |
| 13:00 | run complete applicable tests, links, safety, and diff checks |
| 13:35 | complete an agentic eval separate from deterministic tests |
| 14:05 | obtain independent adversarial review |
| 14:27 | reproduce findings and repair; break |
| 14:50 | rerun gates and prepare a pull request with `Closes #N` |
| 15:20 | human accepts, sends back, rejects, or stops |

Every pair keeps one business outcome responsibility and one engineering
quality responsibility. Participants use local or read-only checks and prepared
fixtures. They do not deploy, provision, change grants, enable live data, change
schedules, promote models, or merge.
