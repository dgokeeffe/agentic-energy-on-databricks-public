# Guardrails and preferences

## Workshop boundaries

- Do not put credentials, tokens or private tenant details in Git or this wiki.
- Use an explicitly named Databricks profile; never select a workspace
  implicitly.
- Do not commit generated deployment state, built artifacts, logs or sensitive
  operational output as source.
- Record the checks and data evidence that support material pipeline claims.

## Working preferences

- Prefer many small Markdown notes over one overloaded plan.
- Keep feature designs at different stages visible; do not force speculative
  research into implementation tasks.
- Use isolated agent sessions for focused research or integration, then save the
  useful context in the relevant page.
- When a session is getting long, stop opening new work. Write the result,
  unresolved questions, and next items before winding down.
- Favor focused sessions and explicit handoffs over one enormous context window.
